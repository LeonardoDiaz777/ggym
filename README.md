# GGym

**Tu entrenador de alto rendimiento para esports:** analiza tus partidas de League of Legends y te dice qué entrenar hoy para subir de rango.

Proyecto académico de la materia de entrenamiento deportivo. La app trata al jugador como un atleta y trabaja cinco dimensiones: mecánica, táctica, cognitiva, física y psicológica.

## Qué hay en este repositorio

| Archivo | Qué es |
| --- | --- |
| `CLAUDE.md` | Reglas del proyecto, pantallas, modelo de entrenamiento y diseño visual |
| `docs/spec.md` | Especificación completa (problema, usuarios, requisitos, legal, métricas) |
| `docs/PLAN.md` | Plan de construcción en 7 fases |
| `docs/PROGRESO.md` | Qué está hecho y qué falta |
| `docs/diseno/prototipo.html` | Prototipo navegable de las 6 pantallas (se abre con doble clic) |

## Las 6 pantallas

1. Bienvenida
2. Inicio
3. Análisis de partida
4. Plan semanal
5. Bienestar
6. Progreso

## Tecnología

- GitHub guarda el código.
- Netlify publica la app.
- Supabase guarda los datos y maneja el inicio de sesión.

Todo en planes gratuitos.
